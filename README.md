# docker-traefik

Proxy local de développement : Traefik v2, Portainer, Maildev et certificats TLS auto-signés (OpenSSL), sur le réseau Docker `traefik` partagé par les projets.
Toutes les commandes passent par `bin/tools` (`bin/tools help`) ; pas de Makefile.
Règles, architecture et documentation : `CLAUDE.md` ou `AGENTS.md`, si présents.
